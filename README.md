# 03 - Refrigeration Knowledge (GitHub Pages)

**Production Domain:** `https://refrigeration-knowledge.github.io`  
**Hosting Target:** GitHub Pages (Static documentation repository output)  
**Target Audience:** HVAC-R apprentices, certificate trainees, mechanical engineering students, technical technicians  
**Design Identity:** Technical documentation system, off-white/canvas background (`#f6f8fa`), graphite typography (`#24292f`), restrained amber/orange accents (`#d97706`), code-style badges, P-h diagrams, in-page TOC.

## Structure & Page Inventory
1. `index.html` - Technical knowledge base homepage with interactive Superheat & Subcooling calculator.
2. `refrigeration-cycle/index.html` - Detailed 4-stage vapour-compression thermodynamic cycle analysis.
3. `refrigeration-compressor/index.html` - Reciprocating, rotary, scroll, and screw compressor mechanics.
4. `condenser-vs-evaporator/index.html` - Heat rejection vs absorption, LMTD, and fin spacing (FPI).
5. `refrigeration-expansion-devices/index.html` - TXVs, EEVs, capillary tubes, and isenthalpic expansion.
6. `refrigeration-controls-sensors/index.html` - Dual pressure cutouts, pump-down cycles, and ratiometric transducers.
7. `refrigeration-energy-efficiency/index.html` - COP, Carnot theoretical limits, and lift minimization.
8. `about/index.html` - Documentation mission, technical sources, and network disclosures.
9. `editorial-policy/index.html` - Scientific rigor, ARCTick licensing compliance, and errata review.
10. `contact/index.html` - Engineering feedback and errata submission intake.
11. `404.html` - Technical documentation 404 error page.

## Technical & SEO Assets
- `robots.txt` - Standard search crawl access with direct sitemap declaration.
- `sitemap.xml` - Canonical index of all 10 indexable routes.
- `favicon.svg` - Technical vector gear/thermodynamic cycle icon.
- `assets/css/style.css` - Custom documentation stylesheet with responsive sidebar and in-page TOC.
- `assets/js/main.js` - Mobile drawer toggle & interactive Superheat/Subcooling calculator.
- `assets/images/ph-diagram-cycle.svg` - Original vector Pressure-Enthalpy (P-h) thermodynamic dome graphic.
- `assets/images/thermo-components.svg` - Original vector refrigeration circuit schematic.
